# Алгоритмы и структуры данных

Учебные реализации алгоритмов на Python и C++: сложность, поиск, графы, строки, машинное обучение.

**Стек:** Python · C++

## Что внутри

**Сложность и поиск**

- `complexity-classes` — примеры алгоритмов разных классов сложности
- `search-comparison` — сравнение линейного, бинарного и интерполяционного поиска
- `data-types` — страница о типах данных

**Графы и геометрия**

- `dijkstra_bellman_ford.py` — алгоритмы Дейкстры и Беллмана — Форда
- `traveling_salesman.py` — задача коммивояжёра
- `polygon_triangulation.py` — триангуляция многоугольника

**Строки и тексты**

- `damerau_levenshtein.py` — расстояние Дамерау — Левенштейна
- `shift_and.py` — алгоритм Shift-And
- `text_search_algorithms.py` — алгоритмы поиска в тексте

**Данные и оптимизация**

- `k-means` — кластеризация k-means
- `genetic_algorithm.py`, `ga_rearrangement.py` — генетические алгоритмы
- `frequent_pattern_growth.py` — алгоритм Frequent Pattern Growth
- `associative-rules` — ассоциативные правила
- `dinamo.py` — задача на динамическое программирование
- `zk_snark.py` — пример zk-SNARK

**Хеширование**

- `sha256` — реализация SHA-256 на C++
- `sha256-homework` — домашнее задание по SHA-256
- `crc8-16` — реализация CRC8 и CRC16

## Запуск

Каждый скрипт запускается отдельно: `python файл.py`. Проект `sha256` собирается в Visual Studio.
