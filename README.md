# Алгоритмы и структуры данных

Учебные реализации алгоритмов на Python: графы, поиск, сжатие, сравнение алгоритмов.

**Стек:** Python

## Что внутри

- `Algorithms/` — базовые алгоритмы
- `Dijkstra_and_Bellman-Ford_algorithms.py` — кратчайшие пути
- `Comparison of searches` — сравнение алгоритмов поиска
- `CRC8_16`, `Frequent_Pattern_Growth`, `Associative rules` — отдельные темы

## Запуск

Каждый файл запускается отдельно: `python файл.py`.
